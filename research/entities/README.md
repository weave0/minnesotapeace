# Entity graph

Canonical organizations, people, and businesses. IDs are durable; names are not keys. Do not merge on similar names, shared city, shared meal-program, or shared address.

990 line items live on claims with `unknown_or_disputed` or `amount_paid` as appropriate. They are **as-filed**, never a homepage TOTAL FRAUD number.

See `990-SOS-HARVEST.md` for the 2026-08-26 pass.
